# 설비 예지보전 데이터 분석 (AI4I 2020)

## 시작하게 된 이유
반도체 식각 설비 PM을 하며, 정해진 주기 대신 설비 상태 데이터로
고장을 미리 알 수 없을까 궁금해서 공개 데이터로 직접 확인하였다.

## 데이터
- UCI AI4I 2020 Predictive Maintenance Dataset (10,000건)
- 온도, 회전 속도, 토크, 공구 사용 시간, 고장 여부와 고장 유형

- 출처: [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset)

## 주요 발견
1. 고장은 전체의 3.39%(339건)
2. 공구 마모 고장은 사용 시간 200분 이후 급증 → 주기 PM으로 대응 가능
3. 열 방출 고장은 온도 차이가 작고 회전이 느릴 때만 발생 → 두 조건을 함께 봐야 함
4. 전력 고장은 전력이 너무 세거나 약한 양쪽 끝에서 발생
5. 과부하 고장은 마모와 토크의 곱이 한계를 넘을 때 발생
→ 사용 시간만으로 막을 수 있는 고장은 일부, 대부분은 상태 데이터 조합이 필요

## 고장 예측 결과 (결정 나무)
| | 원래 변수만 | 원인 변수 추가 |
|---|---|---|
| 고장 감지율 | 39% | 85% |
| 잘못된 경보 | 17건 | 4건 |

현장 관점에서 찾은 원인(온도 차이, 전력, 마모×토크)을 추가하자
고장 감지율이 두 배 이상 올랐다.

## 배운 점과 한계
- 정확도(97~99%)만 보면 성능이 좋아 보이지만, 고장 감지율로 봐야 실제 차이가 보인다
- 고장을 놓치는 비용이 잘못된 경보보다 크므로, 실제 적용 시에는 감지율을 더 높이는 쪽으로 조정이 필요
- 실제 공장 데이터를 바탕으로 만든 합성 데이터라 결과를 그대로 현장에 적용하긴 어렵다.
